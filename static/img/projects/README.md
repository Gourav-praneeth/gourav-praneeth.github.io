# Project screenshots

Add portfolio project images to this folder. Recommended format:

- Use WebP when possible; PNG is also supported.
- Export at 1600 x 1000 pixels (8:5 ratio).
- Keep each image below 500 KB when practical.
- Use lowercase, descriptive filenames with hyphens.

Suggested filenames for the current projects:

- `board-game-rag.webp`
- `auto-research.webp`
- `culinary-companion.webp`
- `tactile-campus-map.webp`

After adding an image, update that project's `image` value in
`content/data.py`. For example:

```python
"image": "img/projects/board-game-rag.webp",
```

The website keeps its designed fallback artwork until an image path is set.
